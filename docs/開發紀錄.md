# 開發紀錄

## 2026-11-23　v1.0.0（Windows 11）

- 需求：`E:\計算尺\計算尺.docx`（主題、六個平台、更新、圖示、語音動態教學、MariaDB＋使用者權限）；
  參考 https://github.com/ldo/infinirule_android（GPLv3）——只參考概念，引擎全部重新撰寫，所以本專案不受 GPL 約束。
- 骨架複製自「資料助秘照顧服務員學科測驗」（Flet 1.1.2＋內建 MariaDB、登入權限、語音教學、更新、備份、單一實例），
  業務層全新（套件 `sr`）。DB 埠 3478、測試 3488、網頁預覽 8660、計算尺單獨預覽 8661。
- 引擎 `sr/rule.py`：一把尺＝1 單位 u；每種刻度定義 數值→u（f）與 u→數值（g），每 1 單位重複（自動環繞）。
  刻度線＝主刻度值之間依放大倍率遞迴切 10／5／4／2 等分，間距小於 6 像素就停，只算看得到的範圍 → 放大 10⁹ 倍仍只有百來條線。
  讀數位數＝半個像素造成的數值差。
- 畫面 `sr/ui/ruleview.py`：三段（上定尺、滑尺、下定尺）各一張 3 倍寬的 Canvas，拖曳時只改 left，移出緩衝區或縮放才重畫。
  手勢只用 on_scale_*（一指＝拖曳、兩指＝縮放；Flutter 不能同時用 pan 和 scale），滾輪 on_scroll 縮放。
  按下位置決定拖什麼：髮線 ±7px 或上下把手＝游標；滑尺範圍＝滑尺；其他＝整把尺；上下空白＝1/10 精細。
- 示範 `sr/demo.py`：算式 → 步驟（髮線、滑尺目標位置、強調刻度、標記），背景執行緒先準備每一步語音（edge-tts 曉臻，快取），
  再依序播放並平滑移動；環繞刻度用 `_near()` 挑最近的一圈。
- 讀尺練習 `sr/rulebiz.py`：題目都用 demo 看得懂的寫法（可以按示範）；相對誤差 ≤ 容許誤差（預設 1%）且沒看示範才算對。
- 坑：Flet `expand=True` 只能用在 Row／Column 的直接子項（放在 Container、Stack、或 wrap=True 的 Row 裡會整塊變灰）；
  同一個控制項不能放兩個地方；Decimal（MariaDB SUM）不能直接和 float 相乘。

## 2026-11-23　線上版（GitHub Pages）

- 不用 Flet 網頁版（要伺服器、手機上慢），改用純 HTML＋JavaScript 重寫畫面：`docs/app/`。
  `rule.js`／`demo.js` 是 `sr/rule.py`／`sr/demo.py` 的逐行移植；驗證方式：同一批算式與刻度線在 Python 和 Node 跑一次比對
  （示範文字、刻度線位置／層級／數字、讀數全部一致；1400 題隨機練習題都能示範）。
- 計算尺用一張 Canvas，每一格畫面重算看得到的刻度線（requestAnimationFrame 合併）；Pointer Events：一指拖曳、兩指縮放，
  滾輪 `preventDefault` → 線上版放大時頁面不會跟著捲動（桌面版 Flet 做不到）。
- 語音：常用算式（PRESETS＋課程示範）每一步預先用 edge-tts 曉臻產生 MP3（`tools/make_pages.py`，以文字對照 `data.js` 的 voice 表），
  其他算式用瀏覽器內建語音（zh-TW）。iPhone 要在按鈕事件裡先播放一次（無聲 WAV 解鎖）。
- 分頁在背景／手機鎖屏時 requestAnimationFrame 會暫停 → 動畫加 setTimeout 保底，示範不會卡住。
- 練習成績、自訂尺型、計算紀錄存 localStorage；PWA（manifest＋sw.js，改程式要遞增 sw.js 的 CACHE）。
- 順手修正（桌面版下一版生效）：sig() 改成四捨五入（2.5→3，原本 Python 銀行家捨入念成 2）、0 不再念成 0.0；
  游標剛好在刻度頭尾時讀數位數不再變成 0 位。
