資料助秘計算尺

會動的虛擬計算尺：拖曳滑尺與游標、無限放大（越放大越精確）、刻度自動環繞像圓形計算尺； 輸入算式，小柯用語音一步一步在計算尺上示範給你看。

📏 開始使用線上版 🎧 語音教學 ⬇ 下載電腦版

功能

📏真的會動的計算尺

拖曳定尺整把移動、拖曳滑尺只動滑尺、拖曳紅色髮線移動游標；游標讀數即時顯示每個刻度。

🔍無限放大

滑鼠滾輪或兩指縮放，刻度一直細分下去，讀數位數跟著變多。

♾️自動環繞

刻度像圓形計算尺一樣首尾相接，乘法永遠不會「超出尺外」。

🗣語音計算示範

2×3.5、7÷2、√2、1.5³、∛27、1/8、sin 30、tan 60、log 2、ln 5、e^2、2^1.5……

☰25 種刻度、7 種尺型

C D CI DI CF DF CIF A B K R1 R2 L Ln S T T2 ST P LL1～LL3 LL01～LL03，也能自訂。

✍讀尺練習

乘除、根號、倒數、三角、對數指數；自動評分，畫出成長折線圖。
